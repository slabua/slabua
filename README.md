# SLB Labs Personal Landing Page

A minimal personal landing page for the QR code on my business card.

## Features

- Dark slate-blue theme
- Responsive layout for phones and desktops
- Brief personal introduction
- Links to social profiles and SLB Labs
- Custom SCSS styling with no external icon dependencies

## Setup

1. Update the profile URLs in `index.md`.
2. Keep the stylesheet at `assets/css/style.scss`.
3. Ensure `_config.yml` is in the repository root.
4. Enable GitHub Pages in the repository settings.

The page is designed to be a stable landing destination for the QR code
on my business card.

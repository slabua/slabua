# Business Card Personal Landing Page

A bilingual personal landing page for the QR code on my business card, built with Jekyll and hosted on GitHub Pages.

## Features

- Dark slate-blue theme with a subtle background image
- Responsive layout for mobile and desktop screens
- English and Japanese language support with a language switch
- Personal profile with a profile picture and introduction
- Organized links to social profiles, SLB Labs, and contact channels
- Custom CSS styling with no external icon library
- Custom typography using Inter and Noto Sans JP
- Analytics integration

## Project Structure

- `index.md` — Page content, profile information, social links, and contact links
- `_layouts/default.html` — HTML document structure, metadata, language selection, and stylesheet loading
- `assets/css/style.css` — Custom theme and responsive styling
- `_config.yml` — Jekyll and GitHub Pages configuration

## Setup

1. Update profile information and destination URLs in `index.md`.
2. Update metadata, language behavior, or external resource references in `_layouts/default.html` as needed.
3. Keep the stylesheet at `assets/css/style.css`.
4. Ensure `_config.yml` is in the repository root.
5. Enable GitHub Pages in the repository settings and configure the appropriate publishing source.

## Purpose

The page serves as a stable, central destination for the QR code on my business card, providing visitors with access to my professional profile, projects, social accounts, and contact channels.
